How javac-packing-slip.txt and javac-messages.txt were made (lesson 9). They are the real output of
JavacPackingSlipProcessor, run by the JDK's javac (25.0.5) on the Java twins below; the KSP port must match them.

  javac --processor-path <ksp solution classes>:<annotations.jar>:<kotlin-stdlib.jar> \
        -processor workbench.ksp.l09.JavacPackingSlipProcessor -Amovemate.household=Okafor \
        -cp <annotations.jar>:<kotlin-stdlib.jar> -d out movemate/*.java
  (and the same without -A on Shape.java, for javac-messages.txt)

----- movemate/Box.java
package movemate;

import workbench.ksp.annotations.Inventory;
import workbench.ksp.annotations.Room;

@Inventory
@Room(name = "hall")
public class Box {
    private final String label;
    private final String room;
    private final int weightGrams;
    private final boolean fragile;

    public Box(String label, String room, int weightGrams, boolean fragile) {
        this.label = label; this.room = room; this.weightGrams = weightGrams; this.fragile = fragile;
    }
}
